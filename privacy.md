# Personal Health Monitor — Privacy Notice

Last updated: 15 October 2026

## Purpose and current status

Personal Health Monitor is a personal prototype operated by the owner of this repository. It is not a service offered to other users. This public repository contains project information; it does not contain the owner's health records or credentials.

Live Oura data access and automated monitoring have not been connected or enabled. This project currently has no authorized ring measurements to analyze. Its private conversation instructions can help organize wellness goals and subjective observations that the owner chooses to share in ChatGPT.

## ChatGPT conversations

Information entered in ChatGPT is processed under OpenAI's applicable policies and the owner's account settings. The owner should review those settings before sharing personal information. This project does not promise particular provider retention or model-training settings.

## Local development

An undeployed local API prototype was developed for evaluation. Its design uses OAuth authorization and stores tokens in the operating-system credential store, with application credentials supplied in a local configuration file. It does not intentionally maintain a health-record database. It is not connected to ChatGPT or authorized to retrieve the owner's data in the current setup. Terminal output or saved reports can create copies if the owner later runs data commands.

## Planned official connection

Before a live connection is enabled, the owner must review the official provider's permissions and data-processing terms. The connection and this notice must be updated to match the actual implemented data flow. No public health dashboard, data resale, advertising use or shared health-record store is part of the current project.

## Public information and control

Project documentation is publicly accessible through GitHub. Do not submit health records or secrets in issues or repository files. The owner manages ChatGPT history and any future connected data using the respective providers' account controls. Removing local files or a plugin does not automatically erase information already processed by another provider.

Contact the project owner through the GitHub account that owns this repository. Use a private channel for personal questions; do not include sensitive information in public issues.
